# MinScenarioSizing

Repository for reproducing the results of the paper *Minimal Scenario-Based Uncertainty Representation
for Optimal Sizing of Isolated Power Systems*

## Code usage
The main file of the project is `src/optimization_function/main_functions/main_ConvertersNumber.m`

The setup is defined in `src/optimization_function/parameters`
